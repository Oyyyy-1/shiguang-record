## 💡 为什么要做「拾光印记」？

大多数日记软件最后都变成&#x4E86;**“只记不看”的文字坟场**——打开就是一片空白页，写完就再也不想翻。

「拾光印记」想把这件事反过来：**输入极轻，回顾极好玩。**

- **3 秒抓瞬间**：散步、通勤、睡前突然冒出一个念头，不用填繁琐表单，打一句话、说一段语音、拍一张照，或者随手画个小太阳盖章，3 秒留住当下。
- **把“翻旧账”变成扭蛋**：心情低落时扭出一件过去的小确幸；迷茫时从过去某段时间里扭出一个曾经困惑过自己的问题，由现在的你亲手回答。
- **让真实记录喂养 AI 复盘**：不上传服务器、不强制联网。当你积累了足够多的日常与迷茫，一键打包筛选后的记录与信息盲区，让 AI 结合 **Human 3.0** 等模型对你发起 1v1 深度采访。

## ✨ 核心功能亮点

### 🗓️ 日历手绘印章 + 微信式 3 秒秒记

- **手绘日历标记**：内置轻量方形画板，笔迹保存为矢量 SVG 缩略图直接贴在日历格子里，铺满一个月自带满满成就感；画过的图案自动收&#x5165;**「我的印章库」**&#x4E00;键复用。
- **无摩擦多模态输入**：首页直出聊天式秒记栏，支持 **🎙️ 微信式实时语音转文字**、**📷 手机原生相机拍照 / 相册选图**、**✏️ 直接盖章保存**，哪怕只拍一张照或只画一个标记也能直接成条。
- **按日期 & 按分类查看**：支持自定义分类标签、关键词全文检索，以及一键切换「🎉 趣味扭蛋」与「🧭 迷茫问题」模式。

### 🎰 双模式扭蛋机：情绪急救 & 跨时空自答

1. **🎉 趣味扭蛋机（快乐罐）**
   - 心情不好或疲惫时，扭一下随机掉出一张过去标记为「趣事」的拍立得回忆卡（带照片、手绘印章与“距今 XX 天”）。
   - 内置**加权防重复算法**：从未被抽中过的旧趣事概率最高，避免反复抽到同一条。
2. **🧭 人生问题扭蛋机（与过去的自己对话）**
   - 平时随手记下当下无解的迷茫问题（支持设置 7 / 30 / 90 天沉淀锁）。
   - 扭蛋时可自由选择**起止日期区间**与“仅抽未作答”，扭出当年写下的问题由现在的你作答——**同一个问题支持多版本回答时间线**，回头看能清晰感受到自己的认知成长。

### 🧠 可选 AI 深度复盘（隐私 100% 掌握在自己手里）

- **纯本地零联网统计**：自动生成**各月迷茫问题密集度条形图**（高亮焦虑高发月份），并自动扫描 **心智 / 身体 / 精神 / 事业** 四象限的信息覆盖度，精准标出信息盲区。
- **自由查看、修改与新建模板**：内置 **Dan Koe Human 3.0 人生规划**、**迷茫密集期痛点扫描**、**快乐源泉与优势提炼** 3 套模板，支持查看全文、自由微调、恢复默认或创建你的专属复盘框架。
- **可复用基础档案 + 逐条私密剔除**：打包前支持逐条取消勾选不想发出的私密日记，自动将统计摘要与盲区提醒拼入 Prompt，减少 AI 无效追问。
- **两种使用方式自由选**：
  - **默认复制模式（零成本）**：一键复制完整上下文包，直接粘贴到你信任的 ChatGPT / Claude / Gemini / DeepSeek 开启深度对话。
  - **可选直连模式（BYOK）**：设置中默认关闭且留空 API Key；若你愿意填入自己的 OpenAI 兼容接口（支持 DeepSeek / OpenRouter / 本机 Ollama），即可在应用内直接开启 1v1 战略采访，并一键将复盘结论存回日历或把新问题投入扭蛋池。
- **随时隐藏入口**：不想要任何 AI 功能？在设置里一键关闭「启用 AI 复盘入口」，回归纯粹的离线手绘日记本。

### 🔒 100% 本地优先，隐私零顾虑

- **无账号、无后端、无云端追踪**：所有文字、压缩后的照片、手绘印章、自定义模板和配置全部保存在你当前设备的浏览器 **IndexedDB** 中。
- **数据完全属于你**：支持随时一键导出 / 导入完整的 JSON 备份包。

## 📱 手机端安装成独立 App（PWA）

打开在线链接：<https://oyyyy-1.github.io/shiguang-record/>

- **iPhone（Safari）**：打开链接 → 点击底部中间 **「分享」** → 选择 **「添加到主屏幕」** → 桌面生成独立圆角图标，全屏运行无地址栏，支持离线打开。
- **Android（Chrome / Edge）**：打开链接 → 点击右上角菜单 `⋮` → 选择 **「安装应用 / 添加到主屏幕」**。

> 💡 首次打开内置了体验数据（含示例印章、趣事和迷茫问题），可以先玩两把扭蛋机感受交互，再点击顶部绿色横幅里的 **「清空开始我的记录」** 一键清零（预设手绘印章与复盘模板会保留）。

## 🛠️ 本地运行与项目结构

纯原生 HTML / CSS / JavaScript 实现，**无需安装 Node 依赖或构建工具**，下载即可运行：

```bash
git clone [https://github.com/Oyyyy-1/shiguang-record.git](https://github.com/Oyyyy-1/shiguang-record.git)
cd shiguang-record
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080 即可完整体验摄像头与语音转文字
```

```text
shiguang-record/
├── index.html       # 主界面结构与各功能弹窗
├── styles.css       # 温暖手账风 UI、移动端安全区适配与扭蛋机动效
├── storage.js       # IndexedDB 本地持久化、默认模板与双扭蛋抽取引擎
├── ai_review.js     # 本地密集度统计、四象限盲区扫描、模板管理与可选 BYOK 对话
├── app.js           # 日历渲染、微信式秒记、语音转文字与 SVG 手绘印章画板
├── manifest.json    # PWA 应用清单
├── sw.js            # Service Worker（网络优先 + 离线缓存兜底）
└── icons/           # 手机桌面图标（PNG + SVG）
```
